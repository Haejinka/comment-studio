# Comment Studio 1.0.0

The first Windows release of Comment Studio: create social-comment PNG overlays locally, with no account or social login.

## Choose your download

- **Comment-Studio-Setup.exe** — normal per-user Windows installation.
- **Comment-Studio.exe** — open directly without installing.
- **START-HERE.txt** — a short plain-text launch guide.
- **Comment-Studio.ico** — the app icon for shortcuts.
- **SHA256SUMS.txt** — checksums for the release files.

**Windows 10/11 x64 (Intel/AMD).** The app uses Microsoft Edge WebView2; the installer can download it when missing. Current binaries are unsigned.

## Included

- Seven TikTok, Instagram, YouTube, and X templates.
- Profile image upload, replacement, verification badges, and editable counters.
- Transparent or solid PNGs at 1×–4× resolution.
- Native Windows image/text clipboard and PNG/ZIP Save As.
- Bulk mode, CSV import, presets, automatic local drafts, and JSON backups.
- Separate light/dark controls for the app and comment image.
- Numbered default export filenames and accurate save-cancellation messages.
- A simple black-and-white app icon.

## Start here

1. Download and open/install the app.
2. Choose a platform and template.
3. Enter a name/comment and optionally upload a photo.
4. Click **Export image** and save the PNG.

## Moving browser drafts

In the browser editor, choose **Draft backups → Export backup**. In Windows, choose **Draft backups → Import backup**. Import replaces the current drafts, so export those first if you want to keep them too.

## Validation

The release was checked with the automated browser/export suite and Rust file-validation/filename tests. A release-executable WebView2 smoke test verified native PNG/ZIP saving, alpha transparency, avatar pixels, clipboard actions, local draft refresh, and save cancellation. PNGs and ZIP contents were decoded and inspected.

## Current limits

- No automatic updater; download new versions from Releases.
- Emoji follows the OS. Proxima Nova is used only when already installed; bundled Inter is the fallback.
- Visual redaction does not delete original text from drafts, backups, or ZIP manifests.
- Large batches at 4× can use significant memory.
