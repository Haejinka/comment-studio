# Comment Studio 1.0.1

## Fixed

- The Windows app now fits inside your monitor’s available desktop space when it opens, accounting for display scaling, the title bar, and the taskbar.
- Export image, Copy image, Copy text, and bulk export controls stay visible in smaller windows while the editor scrolls independently.
- The default window height is smaller, so maximizing is no longer needed to reach the bottom controls.

## Update

Download **Comment-Studio-Setup.exe** to update the installed app, or replace your standalone **Comment-Studio.exe**. Your saved drafts stay on this device. You can save a draft backup before updating from the editor’s backup controls.

The app remains unsigned. Windows may show an unknown-publisher notice.
